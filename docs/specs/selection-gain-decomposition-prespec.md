# 서열 선택 이득의 백본 간 / 백본 내 분해 — 결과 확인 전 동결

> **상태: 결과 확인 전 동결.** 34 표적 격자의 폴딩이 13% 진행된 시점에 쓴다.
> 주 분석은 그 격자가 완성된 뒤에 돌린다. 여기 적힌 값을 결과를 보고 바꾸지
> 않는다.

작성 2026-09-24. 대상 분석: `scripts/benchmark/39_selection_gain_decomposition.py`
(아직 없음).

---

## 1. 풀어야 할 겉보기 모순

동결된 판정 셋이 서로 맞지 않아 보인다.

```
Gate 2 (동결)   백본 **내부**에서 cheap predictor 가 서열을 가르지 못한다
                Δ_Top4 = −0.0366 · 90% LCB −0.0854 · informative 11 → NO-GO
                oracle 상한은 +0.326 이므로 서열층에 신호 자체는 있다
실험 1·2        표적의 **전체 풀**에서는 RF 가 잘 고른다
                Top-20 recall 0.4378 대 무작위 0.2233
                B>=60 에서 두 생성원 모두 ProteinMPNN 점수 상회
실험 3          명시적 백본 배분을 얹어도 추가 이득이 없다
                +0.25 개 [−0.58, +1.25]
```

estimand 가 다르다 — Gate 2 는 백본 **안**에서, 실험 1·2 는 백본을 **가로질러**
고른다. 여기서 검증할 가설은 하나다.

> **RF 의 선택 이득은 주로 백본 *간* 판별에서 오고, 그래서 명시적 백본 배분이
> 더할 것이 없다.**

이것이 맞으면 세 결과가 하나의 기전으로 정리된다. 틀리면 Gate 2 와 실험 1·2
사이의 긴장이 남고, 그 사실 자체를 보고한다.

## 2. 분해 — 2 × 2 요인 설계

선택을 두 축으로 나눈다. **배분**(각 백본에 몇 개를 줄지)과 **백본 내 순위**
(그 안에서 어느 것을 고를지).

```
            백본 내 = RF        백본 내 = 무작위
배분 = RF   rf/rf   (= rf_only)  rf/rand
배분 = 균등 unif/rf              unif/rand  (기준선)
```

네 arm 은 **같은 warm-up 표본과 같은 RF 적합**을 공유한다. 오직 선택만 다르다.

```
총 이득      Total   = Y(rf/rf)   − Y(unif/rand)
백본 간 성분 Between = Y(rf/rand) − Y(unif/rand)
백본 내 성분 Within  = Y(unif/rf) − Y(unif/rand)
상호작용     Inter   = Total − Between − Within
```

`Inter` 는 잔차이며 어느 쪽에도 귀속하지 않는다. 가산성을 주장하지 않는다.

**주 종점은 `Between − Within`** 이다. 양수이고 구간이 0 을 제외하면 가설을
지지한다.

### 2.1 배분 벡터의 정의

`rf/rf` 가 실제로 고른 백본별 개수를 `A_rf` 라 한다. `rf/rand` 는 **같은
`A_rf`** 를 쓰되 각 백본 안에서 무작위로 뽑는다. 균등 배분 `A_unif` 는
`K` 를 백본 수로 나눈 최대잔여 배분이며, 백본별 후보 수가 모자라면 그만큼만
준다.

균등을 기준선으로 쓰는 이유는 후보 수가 백본마다 42 로 같기 때문이다 — 풀
전체에서 무작위로 뽑으면 기댓값이 균등이다.

## 5. 사전에 적어 두는 예측과 그 처리

Gate 2 가 NO-GO 이므로 `Within ≈ 0` 을 예측한다.

```
Between > Within, Between−Within 이 0 제외
    가설 지지. Gate 2 · 실험 1·2 · 실험 3 이 하나의 기전으로 정리된다.
    "RF 의 이득은 백본 간 판별에서 오므로 명시적 배분이 중복이다" 로 쓴다.

Within 이 0 을 제외하고 상당히 큼
    Gate 2 의 estimand 와 이 estimand 가 갈린다는 뜻이다. **사후에 화해시키지
    않는다.** 두 결과를 나란히 보고하고 차이를 estimand 차이로만 기술한다.

Between 과 Within 이 모두 0 포함
    이 예산 구간에서 총 이득 자체가 작다는 뜻이다. Total 과 함께 보고한다.
```

**어느 쪽이 나와도 보고한다.** 결과를 보고 분해 정의나 기준선을 바꾸지 않는다.

## 6. 하지 않는 것

- 새 folding 을 하지 않는다. 완성된 격자를 오프라인 재생할 뿐이다.
- 동결된 Gate 1 · Gate 2 판정을 이 결과로 덮어쓰지 않는다. estimand 가 다르다.
- 실험 3 의 동결 판정(+0.25 [−0.58, +1.25])을 바꾸지 않는다.
- EFBC 를 여기서 계산하지 않는다. coverage 평가는 별도 사전지정을 따른다.
- `Inter` 를 Between 이나 Within 에 흡수시키지 않는다.
- 분해가 가산적이라고 주장하지 않는다.
- 이 분해로 인과를 주장하지 않는다 — 관측된 선택의 귀속이다.
