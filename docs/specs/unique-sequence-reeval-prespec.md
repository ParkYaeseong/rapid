# 고유 서열 기준 few-shot 재평가 — 실행 전 사전지정

> **상태: 실행 전 동결.** 이 문서가 커밋된 뒤에 분석을 돌린다. 여기 적힌 규칙을
> 결과를 보고 바꾸지 않는다. 바꿔야 하면 버전을 올리고 이유를 남긴다.

작성 2026-09-18. 대상 분석: `scripts/benchmark/32_unique_sequence_reeval.py`(아직 없음).

---

## 1. 무엇이 남아 있었나

기존 중복 통제(`28_dedup_controlled_reeval.py`)는 **학습 집합과 겹치는 평가 행만**
제외했다. 두 가지가 남았다.

```
학습 집합 내부 중복   라벨 예산 30 건에 같은 서열이 여러 번 들어갈 수 있다
                      → 실효 고유 라벨 수가 30 보다 적다
평가 집합 내부 중복   같은 서열이 평가에서 여러 번 가중된다
                      → Top-K recall 이 중복 서열에 치우친다
```

리포트도 이것을 미결로 적고 있다 — "남은 집합 내부의 중복과 학습 라벨 예산의
고유 서열 수는 별도 검증 대상이다."

## 2. 실측된 중복 구조

`data/benchmark/cath_pilot_dataset.csv` 기준.

```
전체 행                       9,206
타겟 내 고유 (표적, 서열)      7,965
중복 행                        1,241 (13.5%)
중복을 가진 (표적, 서열) 조합     79
그런 표적                         21
최대 반복                        120 회
```

같은 서열의 반복 라벨은 **완전히 같지 않다.**

```
pLDDT  완전 동일 비율   2.5%
       범위 중앙       0.044
       범위 최대       8.399   ← 판정 문턱 85 에 비해 작지 않다
SoluProt  범위 최대    0.000   ← 서열의 결정론적 함수이므로 정확히 동일
임베딩    같은 서열끼리 최대 절대차 5.662e-07  ← 배치 추론의 float32 잡음
```

## 3. 사전지정 규칙

### 3.1 단위

**추론 단위는 (표적, 고유 서열)이다.** 학습과 평가 양쪽에서 같은 서열은 한 번만
센다.

### 3.2 반복 라벨의 대표값 — 중앙값

```
label(표적, 서열) = median(plddt over 그 조합의 모든 행)
```

평균이 아니라 중앙값을 쓴다. 범위 최대가 8.399 인 조합이 있어 평균은 그 사례에
끌려간다. 중앙값은 2.5% 의 완전 동일 사례에서 평균과 같고, 나머지에서 더
보수적이다. **이 선택은 결과를 보기 전에 한 것이다.**

SoluProt 은 조합 내에서 정확히 동일하므로 어느 값을 써도 같다 — 첫 행을 쓴다.

### 3.3 임베딩의 대표값 — 파일 순서상 첫 행

같은 서열의 임베딩은 최대 5.662e-07 만 다르다(float32 잡음). 평균을 취해
새 벡터를 만들지 않고 **파일 순서상 첫 행**을 쓴다. 결정론적이고 원자료에 있는
값이다.

### 3.4 라벨 예산

```
n_train = 30 고유 서열
```

기존 분석과 같은 수이지만 **단위가 행에서 고유 서열로 바뀐다.** 즉 실효 라벨
수가 기존보다 같거나 많아진다(기존에는 중복이 예산을 먹었다).

### 3.5 표적 포함 기준

```
고유 서열 수 >= 50 (학습 30 + 평가 최소 20)
→ 실측 67 / 77 표적
```

Top-20 recall 을 계산하려면 평가 집합에 20 개 이상이 필요하다. 이 기준으로
**67 표적**이 남는데, 기존 중복 통제 분석이 보고하는 67 표적과 같은 수다.
우연이지만 비교 가능성 면에서 편리하다. 표적 목록이 실제로 같은지는 산출물에
기록한다.

### 3.6 학습 집합 선택

`scripts/benchmark/_selection.py::select_train_indices` 의 `kmeans` 전략을
그대로 쓴다. 붕괴된 고유 서열 행렬 위에서 돌린다. 전략을 바꾸지 않는다.

### 3.7 모델

`02_model_comparison.py` 의 8 개를 그대로 쓴다 - RF · Ridge · XGBoost ·
LightGBM · KNN · GP-RBF · MLP · Random. RF 는 `n_estimators=100`.
**RF 만 보고하지 않는다** - 질문은 "RF 가 최고인가" 가 아니라 "추가 라벨 비용을
감수할 만한 선별 이점이 있는가" 이므로 실용 기준선을 같은 조건에서 함께 낸다.

### 3.8 seed

```
SEEDS = [42, 123, 7, 2024, 31337]
```

기존과 같다.

### 3.9 지표와 불확실성

```
주 지표    Top-20 recall (연속 라벨이므로 정의된다)
보조       Spearman · Top-5 recall
구간       표적 클러스터 부트스트랩 2,000 회 · percentile 95% · seed 20260918
모델 간    같은 부트스트랩 표본에서 **쌍대 차이**를 계산한다
```

쌍대 비교가 요점이다. RF 0.4370 과 Ridge 0.4066 이라는 점추정만으로는 두 모델의
우열을 말할 수 없다. 같은 재표집 표본에서 차이를 계산해야 한다.

## 4. 사전에 정해 두는 해석 규칙

```
쌍대 차이의 구간이 0 을 포함하면   "구별되지 않았다" 로 쓴다.
                                   "A 가 B 보다 낫다" 로 쓰지 않는다.
무작위 대비 구간이 0 을 제외하면   "선별 이점이 있다" 로 쓴다.
                                   배수는 쓰지 않는다 - 라벨 비용이 빠진 비율이다.
```

## 5. 이 분석이 하지 않는 것

- 새 folding 을 하지 않는다. 기존 라벨·임베딩만 쓴다.
- 학습 절차·선택 전략·모델 목록·seed 를 결과를 보고 바꾸지 않는다.
- 표적 포함 기준을 결과를 보고 완화하지 않는다.
- 동결된 v1/v2 판정을 바꾸지 않는다. 별도의 평가축이다.
- 기존 `28_` 산출물을 덮어쓰지 않는다.
- pLDDT 재현 오차를 모형화하지 않는다. 중앙값으로 요약하고 그 한계를 적는다.

## 6. 예상되는 결과와 그 해석

효과가 유지될 수도, 줄어들 수도 있다. **어느 쪽이든 보고한다.**

```
유지되면   중복이 효과의 원인이 아니었다는 근거가 강해진다
줄어들면   기존 수치가 중복에 부분적으로 기대고 있었다는 뜻이고,
           그것이 결과다 - 문턱이나 단위를 되돌려 맞추지 않는다
```

중복 행이 13.5% 이고 최대 반복이 120 회인 표적이 있으므로, 일부 표적에서 값이
눈에 띄게 달라질 수 있다. 표적별 값을 산출물에 남겨 어디가 달라졌는지 볼 수
있게 한다.
